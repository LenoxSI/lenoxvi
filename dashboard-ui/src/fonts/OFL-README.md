# Fonts

Latin subsets, woff2, from Fontsource. Both families are SIL Open Font License 1.1 (https://openfontlicense.org).

- Chakra Petch 400/500/600/700: `--font-display`, headings and the name set large. SemiBold = "oss", Bold = "MIC".
- Inter 400/500/600/700: `--font-sans`, all UI text.

Or load both from Google Fonts (see `lenoxvi-theme.css`).
